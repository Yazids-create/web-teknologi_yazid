# web-teknologi_yazid

Starter dashboard application for the Web Technology course, built with Next.js App Router.

## Getting started

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. For more information about Next.js, see the [Next.js documentation](https://nextjs.org/docs).
